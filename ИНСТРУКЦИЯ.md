# Голосовые и видео-кружки в текст: полная инструкция

Бот: [@golos_v_tekst_211126_bot](https://t.me/golos_v_tekst_211126_bot).

Уже выполнено: бот зарегистрирован в Telegram, токен сохранён в локальном `.env`, профиль настроен, бесплатная модель Whisper tiny скачана на этот компьютер. Код принимает голосовые и кружки, сохраняет мат без отдельного фильтра и доступен всем пользователям в личной переписке.

Сервер успешно размещён 21 ноября 2026 года в Render, пространство **My Workspace**, тариф **Free ($0)**. На момент проверки статус — **Live**, webhook Telegram подключён, ошибок доставки нет. Домашняя копия остановлена: компьютер можно выключать.

- [Панель управления сервером](https://dashboard.render.com/web/srv-dc0u8r142hec73ch884g).
- [Исходники и эта инструкция в GitHub](https://github.com/Maksim993/golos-v-tekst-bot).

Для обычного использования достаточно открыть бота и отправить запись. Раздел 3 нужен для повторной установки, если сервис придётся создавать заново.

## 1. Как им пользоваться

1. Открой ссылку бота в Telegram и нажми «Старт».
2. Найди голосовое сообщение или видео-кружок в любой переписке, выбери «Переслать» и укажи этого бота. Или запиши голосовое прямо боту.
3. Бот пришлёт текст ответом на запись. Никакие команды для каждой расшифровки вводить не нужно.
4. Отправь ссылку знакомым: они тоже смогут пользоваться ботом. Добавлять их в список доступа не нужно.

Обычные видео, файлы и музыкальные аудиотреки не обрабатываются. В групповых чатах бот ничего не делает: каждый отправляет записи в личный чат с ботом.

## 2. Что бесплатно и где ограничения

Распознавание выполняет **Whisper через faster-whisper** на том же компьютере или сервере, где запущен бот. За минуты распознавания платить не нужно, ключ OpenAI API и подписка на него не нужны. Название OpenAI у исходной модели Whisper не означает использование платного API.

Для работы при выключенном домашнем компьютере код должен работать на внешнем сервере. Здесь предусмотрен **Render Free**. Это бесплатный вариант с ограничениями, а не гарантия непрерывной доступности:

- После 15 минут без входящих запросов Render останавливает бесплатный сервис. Новое сообщение Telegram вызывает входящий запрос, который запускает сервис снова; первый ответ может прийти через минуту или больше. При неуспешной доставке Telegram повторяет запросы.
- На бесплатном сервисе мало процессорного времени и 512 МБ памяти. Поэтому выбрана лёгкая модель `tiny`, одна запись обрабатывается за раз, а следующие ждут в очереди. На русском возможны ошибки, особенно на шумной записи и мате. Сам бот ничего не заменяет звёздочками.
- Лимиты по умолчанию: запись до 5 минут и до 20 МБ; очередь до 10 записей, из них не больше 3 от одного пользователя. Это подходит для небольшой компании, а не массового сервиса.
- Очередь находится в памяти. При перезапуске сервера уже принятые, но не завершённые задания могут потеряться — такие записи нужно отправить ещё раз.
- У Render есть месячные лимиты бесплатных часов, трафика и сборки. Тариф нельзя считать обещанием бесплатной работы навсегда. Если сервис требует банковскую карту для проверки аккаунта, это нельзя надёжно обойти: остановись, если такой вариант тебе не подходит.

Компьютер можно выключать **после успешного размещения в Render**. Запуск через `run.cmd` работает только пока включён этот компьютер.

Условия проверены 21 ноября 2026 года: [Render Free](https://render.com/docs/free), [ресурсы тарифов Render](https://render.com/docs/compute-plans), [Telegram Bot API](https://core.telegram.org/bots/api#setwebhook), [faster-whisper](https://github.com/SYSTRAN/faster-whisper). Перед размещением проверяй актуальные условия в аккаунте.

## 3. Самостоятельное размещение в Render, без команд на компьютере

Этот раздел нужен, если размещение не удалось завершить автоматически. Если сервер уже работает, переходи к разделу 4.

### Шаг A. Помести код в GitHub

1. Войди в [GitHub](https://github.com/). Аккаунт для репозитория может быть бесплатным.
2. Открой [создание репозитория](https://github.com/new).
3. Имя: `golos-v-tekst-bot`. Выбери **Public**, чтобы Render мог скачать код без отдельного доступа к приватному репозиторию. Публичными будут код и инструкция, не переписки и не токен.
4. Добавь начальный README и нажми **Create repository**.
5. На странице репозитория нажми **Add file → Upload files**.
6. Загрузи из папки проекта только эти файлы: `bot.py`, `speech.py`, `requirements.txt`, `Dockerfile`, `render.yaml`, `.dockerignore`, `.gitignore`, `.env.example`, `README.md`, `ИНСТРУКЦИЯ.md`. Тесты можно добавить отдельно, для запуска они не нужны.
7. Нажми **Commit changes**.

**Не загружай `.env`**, `.venv`, `.models`, `test-output`, архивы с личными данными или токеном. Нужен именно `.env.example` с пустой строкой токена. Для ручной загрузки может пригодиться готовый архив в папке `dist`: в него включаются только исходники и инструкция, без секретов.

### Шаг B. Создай бесплатный сервис

1. Войди в [Render](https://dashboard.render.com/), создай бесплатный аккаунт, если его ещё нет. Выбирай бесплатный рабочий план и не подключай платные дополнения.
2. Выбери нужное рабочее пространство. В текущей настройке подтверждено **My Workspace**.
3. Нажми **New → Blueprint**. Если меню называется иначе, найди создание ресурсов из `render.yaml`.
4. Подключи репозиторий `golos-v-tekst-bot`. Для публичного репозитория можно указать его URL, если интерфейс предлагает такой вариант.
5. Render прочитает `render.yaml` и предложит один **Web Service** на плане **Free**. Никакие базы данных и фоновые платные Workers здесь не нужны.
6. В поле `TELEGRAM_BOT_TOKEN` вставь значение из локального `.env`: только текст после `TELEGRAM_BOT_TOKEN=`, без имени переменной и без кавычек. Если токен потерян, открой свой чат с [@BotFather](https://t.me/BotFather) и найди сообщение о создании этого бота. Восстановить доступ также можно через `/mybots` → нужный бот → API Token.
7. `WEBHOOK_SECRET` генерируется Render автоматически. Это отдельный случайный секрет для проверки запросов Telegram; его не нужно сообщать пользователям.
8. До подтверждения проверь, что цена сервиса **$0 / Free**. Если предложен платный тариф, вернись к выбору Free. Не соглашайся на платное размещение ради продолжения инструкции.
9. Подтверди создание. Дождись сборки и статуса **Live**. Первая сборка скачивает библиотеки и бесплатную модель и может занять несколько минут.

Модель скачивается во время сборки контейнера. Telegram-токен не записывается в образ. Во время запуска файлы модели уже находятся в контейнере, поэтому новый запуск не скачивает её заново.

### Шаг C. Проверь

1. В логах Render должно появиться сообщение «Бот запущен. Ожидаю голосовые и видео-кружки» и затем сообщение об успешном запуске webhook.
2. Открой [бота](https://t.me/golos_v_tekst_211126_bot), нажми «Старт» и отправь короткое голосовое с понятной речью.
3. Проверь кружок, а затем запись с матом. Если модель ошиблась в слове, это ошибка распознавания; фильтра мата в коде нет.
4. Выключи компьютер и отправь запись с телефона. Ответ подтвердит, что бот работает на сервере.
5. После долгого перерыва дождись пробуждения сервера, не отправляя сразу много копий одной записи.

Ссылка вида `https://....onrender.com` служебная. В текущей реализации при открытии её в браузере возможен ответ 404: сайт здесь не предусмотрен. Проверяй статус сервиса в Render и работу самого Telegram-бота.

### Если создаёшь Web Service вручную вместо Blueprint

Выбери **New → Web Service**, тот же репозиторий, среду **Docker**, план **Free** и отключи автоматические платные дополнения. Добавь переменные в разделе Environment:

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен из `.env` |
| `WEBHOOK_SECRET` | Случайная строка не короче 32 символов из букв, цифр, `_` и `-`; используй Generate |
| `RUN_MODE` | `webhook` |
| `WHISPER_LANGUAGE` | `ru` |
| `WHISPER_CPU_THREADS` | `1` |
| `MAX_DURATION_SECONDS` | `300` |
| `MAX_PENDING_JOBS` | `10` |
| `MAX_PENDING_PER_USER` | `3` |
| `ALLOWED_USER_IDS` | Пустое значение — доступ всем |

`PUBLIC_URL` не нужен: Render автоматически предоставляет `RENDER_EXTERNAL_URL`, и код использует его для webhook. `WHISPER_MODEL` тоже не переопределяй: Dockerfile уже задаёт путь к скачанной модели `/app/model`. `MODEL_OFFLINE=1` задан в образе.

## 4. Управление и устранение проблем

- **Бот молчит после перерыва.** Подожди пробуждения бесплатного сервиса. Если ответа нет несколько минут, проверь статус и логи Render. При необходимости отправь запись ещё раз.
- **Ошибка InvalidToken / Unauthorized.** Проверь `TELEGRAM_BOT_TOKEN` в Environment. После изменения настроек сохрани их и перезапусти сервис.
- **Ошибка Conflict / другая копия бота.** Останови `run.cmd` на компьютере и лишние копии сервера. На один токен должна работать одна копия.
- **Ошибка модели / недостаточно памяти.** Проверь, что на Free используется модель из Dockerfile, а не `small` или `medium`. Попробуй более короткую запись. Слабый сервер может не справиться с отдельной записью даже при небольшой аудитории.
- **Текст неточный.** Перешли более чёткую запись. На сервере с несколькими гигабайтами памяти можно собрать образ с `--build-arg WHISPER_MODEL=small`; это повышает требования и замедляет обработку. На Render Free такой переход не рекомендуется.
- **Не нужны ограничения доступа.** Оставь `ALLOWED_USER_IDS` пустым. В этой версии так и настроено.
- **Нужно перезапустить.** В панели сервиса Render выбери ручной перезапуск или повторное размещение текущей версии. Саму модель или токен заново создавать не нужно.
- **Нужно обновить код.** Измени файлы в GitHub и запусти ручной deploy в Render. Автоматическое размещение при каждом изменении отключено, чтобы случайные правки не перезапускали бота.
- **Токен случайно опубликован.** В BotFather выбери этого бота, отзови скомпрометированный токен и замени его в Render Environment и локальном `.env`. Старую опубликованную копию секретом считать уже нельзя.

Если Render запрашивает карту или не предоставляет Free для твоего аккаунта, инструкция не обещает способа обойти это требование. Без бесплатного внешнего вычислителя работа при выключенном компьютере невозможна; одним Telegram-аккаунтом вычисления для Whisper не предоставляются.

## 5. Локальный запуск для проверки или запасной сервер

На этом компьютере токен и зависимости уже подготовлены. Открой `run.cmd` и оставь окно работать. Этот режим использует `RUN_MODE=polling`; при запуске polling библиотека удалит существующий webhook, поэтому он отключит доставку на Render. Не запускай локальную копию одновременно с облачной.

На другом Windows-компьютере установи Python 3.11–3.13, скопируй проект и свой `.env`, затем запусти `run.cmd`. Скрипт установит зависимости и скачает модель при первом запуске. Библиотеки обработки звука входят в зависимости, отдельная установка FFmpeg не нужна. Если отсутствует `VCRUNTIME140.dll`, установи официальный [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

Проверка из PowerShell в папке проекта:

```powershell
.\.venv\Scripts\python.exe bot.py --check
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe bot.py
```

`--check` проверяет заполнение настроек и импорт библиотек без отправки сообщений и без скачивания модели. `--download-model` скачивает или проверяет модель, не запуская Telegram-бота.

Для уже имеющегося Linux-сервера с Docker Compose:

```bash
docker compose up -d --build
docker compose logs -f --tail=100
```

Команды выполняются в папке проекта с заполненным `.env`. Compose сам перезапустит контейнер после сбоя или перезагрузки сервера. Этот способ не требует публичного домена и открытого входящего порта, потому что использует polling.

## 6. Хранение данных

Запись скачивается с Telegram на компьютер/сервер бота, распознаётся там и удаляется после обработки, в том числе при обычной ошибке. Внешний платный сервис распознавания не вызывается. Хостинг, на котором работает бот, технически имеет доступ к своему окружению.

Бот не ведёт базу расшифровок и не записывает текст записей или токен в свои журналы. Сообщения остаются в Telegram. После аварийного завершения процесса временные файлы могут остаться в системной временной папке; на Render файловая система контейнера непостоянная. Очередь не сохраняется между перезапусками.
